## Parts Compatibility Checklist ✓

Before buying, verify:
- [ ] ESP32 uses 5V logic (most DOIT boards do)
- [ ] Relay module accepts 5V input
- [ ] CT sensor output matches ESP32 ADC range (0-1.65V optimal)
- [ ] Maximum load current < 10A (for safety relay)
- [ ] Available space for enclosure

## Sample Shopping List for First Timer

Copy this list when ordering online:

```
1x ESP32 DevKit V1 (NodeMCU-32S)
1x 5V 1-Channel Relay Module
```
